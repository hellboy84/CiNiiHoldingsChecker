## プライバシーポリシー / Privacy Policy

本拡張機能は、ユーザーのプライバシーを尊重し、以下の方針に従います。

### 収集するデータ

本拡張機能は、ユーザーの操作に基づき、CiNii Booksの雑誌詳細ページから以下の情報を取得します：

- 雑誌タイトル・URL
- ユーザーが指定した巻号
- 所蔵館名・図書館コード

### データの保存

取得したデータはすべてブラウザのローカルストレージ（chrome.storage.local）にのみ保存されます。

### 外部への送信

外部サーバーへのデータ送信は一切行いません。

### 個人情報

本拡張機能は、個人を特定できる情報を収集・使用・共有しません。

### 第三者への提供

ユーザーのデータを第三者に販売・提供することはありません。

### お問い合わせ

本拡張機能に関するお問い合わせは、[GitHubのIssues](https://github.com/hellboy84/CiNiiHoldingsChecker/issues)からお願いします。

---

This extension respects user privacy and adheres to the following policies.

### Data Collected

This extension retrieves the following information from CiNii Books journal detail pages based on user actions:

- Journal titles and URLs
- Volume/issue numbers specified by the user
- Library names and library codes

### Data Storage

All retrieved data is stored exclusively in the browser's local storage (chrome.storage.local).

### Data Transmission

No data is ever transmitted to any external server.

### Personal Information

This extension does not collect, use, or share any personally identifiable information.

### Third-Party Sharing

User data is never sold or provided to any third party.

### Contact

For inquiries about this extension, please use [GitHub Issues](https://github.com/hellboy84/CiNiiHoldingsChecker/issues).
